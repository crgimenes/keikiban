Sessions

      

        
        
      

    

    

    
Every client session on the server, the busiest first.
      Cancel stops the running query; the transaction stays open until the
      client commits or rolls back. Terminate closes the connection and rolls
      its transaction back.

    

  


  

    

      
Index health

      

        
      

    

    

    

    


    
Invalid indexes

    
Leftovers of a failed CREATE INDEX CONCURRENTLY: they are
      maintained on every write but never used. Safe to drop, then recreate
      if still wanted.

    


    
Duplicate indexes

    
Column list equal to, or a leading prefix of, another
      index on the same table. The wider index already serves these queries.
      Verify before dropping: opclass or ordering differences can matter.

    


    
Unused indexes

    

    


    
Tables scanned sequentially

    
Large tables where sequential scans dominate: a missing
      index or stale planner statistics. Cumulative numbers, read with the
      stats age above in mind.

Migrations

      

        
      

    

    


    

      
      

    


    


    
Pending

    
Migration files newer than the applied version, in the
      order they would run. Run shows their exact SQL first.

    

    

      
      
    


    
Drift

    
The live schema compared with the latest snapshot in the
      migrations directory. Capture turns the difference into a reviewed
      up/down pair and records it as applied.

    

    

      
      
    


    

      

      

      

        
        
      

    

    

  


  

    

      
Maintenance

      

        
      

    

    


    
Transaction ID wraparound

    
PostgreSQL shuts down writes if transaction IDs are ever
      exhausted. Autovacuum normally freezes rows well before that; this is
      how close the database is to the freeze threshold.

    

    


    
Long-running transactions

    
A transaction open for a long time keeps its locks and
      stops vacuum from cleaning dead rows anywhere in the database. Idle in
      transaction is the dangerous one: nothing is running, yet everything
      waits.

    


    
Dead rows

    
Rows already deleted or replaced, still occupying space
      until vacuum reclaims them. Estimates from the statistics collector.

    

    


    
Sequences

    
How much of each sequence range is spent. An integer
      column overflowing its sequence stops inserts.

    

  


  

    
Connections

    

    

    

      
    

    
The first connection is the default: keikiban attaches to
      it when it opens. Only one connection is open at a time, so connecting
      to another closes the current one.
