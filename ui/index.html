Invalid indexes

    
Leftovers of a failed CREATE INDEX CONCURRENTLY: they are
      maintained on every write but never used. Safe to drop, then recreate
      if still wanted.

    


    
Duplicate indexes

    
Column list equal to, or a leading prefix of, another
      index on the same table. The wider index already serves these queries.
      Verify before dropping: opclass or ordering differences can matter.

Tables scanned sequentially

    
Large tables where sequential scans dominate: a missing
      index or stale planner statistics. Cumulative numbers, read with the
      stats age above in mind.
